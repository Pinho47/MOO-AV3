# AOO-AV3

Projeto da AV3 da disciplina de Modelagem Orientada a Objetos.

## Projeto

Modelagem Orientada a Objetos de uma Plataforma para Psicólogos.

## Objetivo

Produzir um dossiê completo e rastreável contendo requisitos,
regras de negócio, modelos UML, persistência, arquitetura,
qualidade, processo e documentação, de forma que a modelagem
possa orientar uma futura implementação.

## Escopo mínimo

- Identidade e acesso
- Administração
- Psicólogos
- Clientes/pacientes
- Agenda
- Atendimento
- Auditoria
- Funcionalidade de inovação

## Entregas previstas

- Documento de visão
- Requisitos funcionais e não funcionais
- Regras de negócio
- Casos de uso
- Diagramas UML
- DER e modelo relacional
- Dicionário de dados
- Mapeamento objeto-relacional
- Plano de qualidade
- Matriz de rastreabilidade
- Dossiê final
- Arquivos editáveis
- Vídeo-pitch
